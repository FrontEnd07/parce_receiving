# Parcel Receiving — инструкция для тестировщика BLE-весов

## Что нужно

- Android-смартфон с Bluetooth и доступом к геолокации.
- Включённые электронные весы с BLE.
- APK `app-release.apk`.

## Установка

1. Передайте APK на смартфон и откройте файл.
2. Разрешите установку из этого источника, если Android покажет запрос.
3. Откройте приложение **Parcel Receiving**.
4. При первом запуске разрешите Bluetooth и геолокацию. Без этих разрешений Android может не показать BLE-устройства.

## Проверка подключения

1. Включите весы и поместите телефон рядом с ними.
2. На экране «Диагностика весов» нажмите «Поиск BLE-устройств».
3. Найдите весы в списке. Если название пустое, ориентируйтесь по идентификатору и уровню RSSI: чем ближе к нулю, тем обычно сильнее сигнал.
4. Нажмите «Подключить». Статус должен смениться на «Подключено».
5. По очереди нажмите команды **Брутто**, **Нетто**, **Тара**, **Ноль**.
6. Для каждой команды положите известный груз на весы, затем уберите его. Повторите при необходимости.

## Что прислать разработчику

Сделайте скриншоты экрана для каждого случая:

- подключение к весам;
- показания без груза;
- показания с известным грузом (укажите настоящий вес и единицу измерения);
- результат каждой из четырёх команд;
- любые сообщения об ошибках.

Особенно важен блок «Журнал диагностики»: пришлите строки **HEX** и **ASCII** для каждого теста. Не редактируйте эти данные. По ним будет реализован подтверждённый парсер веса и проверка стабильности показаний.

## Важно

Текущая версия отправляет только подтверждённые Co5-команды в бинарном виде и показывает ответ весов как RAW HEX/ASCII. Она **не интерпретирует** ответ как вес, так как формат ответного пакета Co5 пока не подтверждён на реальном оборудовании.

Если поиск не находит весы, проверьте, что они не подключены к другому телефону, Bluetooth и геолокация включены, а разрешения приложению выданы в настройках Android.
